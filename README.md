# reino-vivo-peteco-lab-test
Página de testes pública do Reino Vivo Peteco Lab. A aplicação original permanece no projeto Lovable.

## LIVE e direção no PC

Na pasta do repositório, inicie o servidor com `node tools/live-local.cjs`.

| Janela | Endereço |
| --- | --- |
| LIVE para captura vertical | [127.0.0.1:8787](http://127.0.0.1:8787/) |
| ADMIN para direção | [127.0.0.1:8787/admin/](http://127.0.0.1:8787/admin/) |

Abra as duas páginas no mesmo navegador e perfil. A aba ADMIN roda a vila e grava seu progresso. A LIVE recebe a cena e pode ser capturada pelo TikTok LIVE Studio. Clique uma vez na LIVE para liberar o áudio do navegador.

O ADMIN no GitHub Pages oferece QA público e exportação do salvamento. Na primeira abertura do ADMIN local, importe esse arquivo antes de iniciar a vila se quiser continuar de onde parou. A transferência copia o progresso. Cada endereço conserva seu próprio armazenamento.
